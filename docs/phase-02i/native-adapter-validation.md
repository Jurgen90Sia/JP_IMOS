# Controlled native adapter — standalone validation

Date:18 November2026. Task5 of the [implementation plan](atomic-host-implementation-plan.md). **Actual SketchUp execution of this adapter: NOT RUN.** The standalone SDK double is original test software; it is not SketchUp and does not qualify native undo, event timing, save/reopen or tolerance behavior.

## Scope and entry

`NativeHarness.reserve_scratch(directory:)` reserves a fresh, nonexistent randomized `.skp` path in an existing directory selected by the trusted harness as its workspace output root. It does not save or overwrite a file. The caller must save a new controlled scratch copy at exactly that path before `NativeHarness.register(reservation:,model:,idle_asserted:true)` can register it. A reservation is a private process object, not an imported path/JSON input. The registry issues the separate opaque ControlledContext capability binding exact canonical saved path, model reference and open-incarnation anchor; copied reservations/capabilities fail. Only one live port is allowed per model and per reserved path. Reattachment shares that port and authority.

Registration requires the current model, supported experimental major21–26, no edit path and an initially unmodified saved copy. The major guard permits experiments, not a compatibility claim for every build. The directory argument is a trusted workspace choice, not a general path importer or a security boundary against arbitrary Ruby code. The native adapter never saves a model or picks the user's original file. Silent saves can affect user data, so copying/saving belongs to the explicitly controlled harness, not automatic adapter initialization. [Model save API](https://ruby.sketchup.com/Sketchup/Model.html#save-instance_method).

`NativeHarness.settled(context:,idle_asserted:true)` issues a one-use controlled grant only outside busy/native/gateway phases and edit contexts. `dispatch(context:,action:){...}` invalidates synchronously before known undo/redo/save/switch/open/close actions, then leaves the gate closed for the next settled assertion/full read. Runtime numeric policy is derived from the actual Ruby version/platform and Math backend; Reader/Application reject a different caller policy before geometry dispatch.

Detaching removes mutation capability and quarantines the existing authority; it does **not** claim a model-close event or reset quarantine. A retained lifecycle observer tracks the model until actual close/open/new-wrapper transition. Reattachment cannot escape read-only state; explicit Recovery still requires a fresh grant and full inspection. Only an observed actual incarnation transition closes the old Registry anchor. Failed observer registration revokes the partial capability and cannot be reused as an unwatched port.

## Geometry and bounded inspection

Only Group containers and rectangular substrate/surface Group solids are emitted. Every actual coordinate is world mm converted once to SDK inches; all group transforms remain identity. Native inspection compares a bijection of8 vertices within0.001mm per axis,12 expected edges,6 directed quads with one loop each, outward normals, manifold status and positive volume within max(1e-6mm3,expected×1e-8). These are JP experimental tolerances, not manufacturer/imos construction rules. SDK lengths are internally inches; cubic conversion follows dimensional arithmetic. [Length API](https://ruby.sketchup.com/Length.html), [Group volume/manifold API](https://ruby.sketchup.com/Sketchup/Group.html#volume-instance_method).

Global scanning traverses nested Groups/ComponentInstances incrementally with Enumerator frames, charging before processing each yielded entity. It retains one active-definition identity set using native transient entity IDs, so recreated Ruby wrappers do not bypass cycle detection. It never pre-enqueues an entire native collection. Tagged copies/orphans, unknown children, locked/shared/gluable groups and nonidentity transforms fail. Geometry failures retain the logical part reference. PIDs remain hints in RAM; reading never rewrites stored hints. Empty projects create no empty Group.

Entity tag dictionaries are closed, capped at1024 bytes per tag and parsed/copied with the **same CoreBudget** supplied through the shared VisitBudget. There is no per-entity budget reset. Native read/preparation/apply retain the existing cumulative work/text/visit caps. SDK calls that return a single native value are checked as soon as returned; this does not claim control over undocumented internal SDK allocations.

## SDK version findings

- Ground-plane add_face can override input winding; emitted faces are checked and reversed against the intended normal when needed. [Entities add_face](https://ruby.sketchup.com/Sketchup/Entities.html#add_face-instance_method).
- Group.glued_to was added in2021.1. The2021.0 path uses the older non-gluable Behavior.is2d? guard and only calls glued_to when available; this is tested with the method absent. [Group](https://ruby.sketchup.com/Sketchup/Group.html#glued_to-instance_method), [Behavior](https://ruby.sketchup.com/Sketchup/Behavior.html#is2d%3F-instance_method).
- AppObserver.onCloseModel is2027-only and is not required by this21–26 experiment. ModelObserver.onDeleteModel plus existing AppObserver new/open/activate/quit hooks provide lifecycle invalidation. Actual delivery/wrapper behavior remains Task6. [AppObserver](https://ruby.sketchup.com/Sketchup/AppObserver.html#onCloseModel-instance_method), [ModelObserver](https://ruby.sketchup.com/Sketchup/ModelObserver.html#onDeleteModel-instance_method).

## Observer protocol

Expected own start/commit notices are accepted only in the controller's matching phase/order; expected abort is accepted only during abort. They acknowledge the guarded operation without model writes or extra native operations. The controller already holds the shared busy guard and publishes/revokes process objects only after full post-checks. Unexpected/duplicate/out-of-phase events quarantine. Known gateway notifications need no second invalidation because it happened before dispatch. No observer mints a grant or edits geometry/source. The SDK documents delayed transaction notifications and lacks a current-operation query; expected event sequencing and actual foreign-observer interference remain unqualified until observed in SketchUp. [ModelObserver API](https://ruby.sketchup.com/Sketchup/ModelObserver.html).

It does not save, undo, reopen or compensate automatically; disk_saved is explicitly false. Evidence I/O failures do not undo a committed model change, so do not blindly replay initial application.
